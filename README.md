# Apex AI Consumer Index

A responsive, interactive, single-page field guide to the consumer AI market described in **“The Top 100 Gen AI Consumer Apps — 7th Edition”** by Olivia Moore (a16z, October 5, 2026).

## Run locally

Open `index.html` directly, or serve this folder with any static web server. The page has no build step, external JavaScript, fonts, or image dependencies.

## Deploy

The site is designed for GitHub Pages from the `main` branch, `/` (repository root). Once Pages finishes its first build, it will be available at:

`https://<github-owner>.github.io/apex-ai-consumer-index/`

## Data & attribution

The figures and interpretations are based on the supplied notes and the source article. Traffic data is attributed there to Similarweb and Sensor Tower; spending observations to YipitData U.S. panels. Panel figures, reported milestones, and founder claims are labeled in the page and should not be treated as a census or independently verified company revenue. Comparisons may use different cohorts and time windows.
